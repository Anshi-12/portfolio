# Anshita Shah — Portfolio

My personal portfolio: a white-and-lavender "cloud desk" where everything on the desk is clickable.

- **Cameo** — a 3D-style avatar of me that follows your cursor and says hi.
- **Projects** — a Three.js sculpture of ~3,000 cubes that rebuilds itself into a new shape for each project as you scroll (including the same brain geometry as drsavan.com).
- **Roles** — a draggable 3D ring gallery of leadership roles and awards.

Plain HTML/CSS/JS, no build step. Three.js r128 from cdnjs.

## Run locally
Open `index.html` in a browser, or `npx serve .`

## Deploy
Static site — import the repo into Vercel (framework preset: **Other**, no build command) or create a Render **Static Site** with publish directory `.`.
